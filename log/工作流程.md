## 2. 构建

```bash
make dirs                 # 创建 build/
make elf                  # 交叉编译 bootblock / 内核 / 4 个 app
```

Task 1/2 制作镜像（官方 createimage，注意 `--extended` 是两个减号）：

```bash
chmod +x ../createimage                    # git 里记的是 644，执行前临时加 +x
cd build && ../createimage --extended bootblock main && cd ..
```

> ⚠️ shell 的工作目录在多次调用之间会持续保留：`cd build` 之后，后续命令都相对
> `build/` 执行。建议每条命令都带绝对路径或先 `cd /home/stu/oslab-course/huangyihao24`。
>
> 另外 `pgrep qemu-system-riscv64` 不带 `-f` 会因进程名超过 15 字符而报
> "will result in zero matches"，检查残留进程要用 `pgrep -af qemu-system-riscv64`。

Task 3 起改用自建 createimage：

```bash
make image                # cd build && ./createimage --extended bootblock main 2048 auipc bss data
```

常用检查：

```bash
riscv64-unknown-linux-gnu-readelf -h build/<elf>   # 入口地址
riscv64-unknown-linux-gnu-readelf -lW build/<elf>  # program header（看 filesz/memsz）
riscv64-unknown-linux-gnu-nm   build/<elf>         # 符号（__bss_start / __BSS_END__ 等）
xxd -s $((0x1f0)) -l 16 build/image                # 镜像尾部：扇区数字段 + 55aa 签名
```

## 3. 运行

```bash
make run
```

启动后：
1. 等约 **6 秒**（U-Boot autoboot 走完，末尾会执行 `virtio read 50200000 0 2` 把镜像
   第 0/1 扇区读入 0x50200000）；
2. 出现 `=> ` 提示符后输入 **`loadboot`**（只做 `mret` 到 0x50200000，bootblock 已在内存）；
3. 无需按键停止 autoboot。

退出 QEMU：`Ctrl+a` 后按 `x`，或 `Ctrl+a` 后按 `c` 再输入 `quit`。

## 4. 自动化验证

- 后台启动 QEMU，全部输出重定向到 `.scratch/<task>-qemu.log`；
- 用管道 + `sleep` 按时序注入输入（`loadboot`、回显字符、taskid、程序名），每步留足延时；
- 整体套 `timeout` 防卡死；结束时检查并清理残留 `qemu-system-riscv64` 进程；
- 验证脚本一律放 `.scratch/`，任务验收后删除。

骨架：

```bash
( sleep 6; printf 'loadboot\n'; sleep 10 ) \
  | timeout 25 ~/OSLab-RISC-V/qemu/riscv64-softmmu/qemu-system-riscv64 \
      -nographic -machine virt -m 256M \
      -kernel ~/OSLab-RISC-V/u-boot/u-boot -bios none \
      -drive if=none,format=raw,id=image,file=build/image \
      -device virtio-blk-device,drive=image \
      -monitor telnet::45454,server,nowait -serial mon:stdio \
  > .scratch/xxx.log 2>&1
```

注入后检查（串口输出带 `\r`，用 `grep -a`）：

```bash
grep -a "It's Dreamerhyh's bootloader" .scratch/xxx.log
pgrep -af qemu-system-riscv64 || echo "无残留 QEMU 进程"
```

## 5. 字节计数口径（收官注解）

`createimage` 每个文件"占用的字节数"= **该 ELF 所有 PT_LOAD 段的 `p_filesz` 之和**
（`scan_elf()` 逐个累加），`NBYTES2SEC()` 向上取整为扇区数。要点：

- **按 `p_filesz`，不是 `p_memsz`**：bss 不计入镜像（由 head.S / crt0 运行时清零）；
- **与官方 createimage 口径不同**：官方产物按 `p_memsz` 写字并做 0x400 对齐
  （Phase 0 §6），我们是 project-self 的 `p_filesz`，两者不可混用；Task 1/2 用
  官方已结束，之后统一用自建。
- **`0x1fc` 的内核扇区数** = `NBYTES2SEC(main 的 p_filesz 和)`，即"内核实际占用"，
  不是分配的 32 也不是 memsz；bootblock 按此精确读入。
- **AppInfo 的 `sector_num`** = 该 app 的 `NBYTES2SEC(p_filesz)`（apps.img 内），
  `start_sector` 为相对扇区号。

## 6. 调试

```bash
make debug     # QEMU 加 -s -S，停在第一条指令并监听 :1234
make gdb       # riscv64-unknown-linux-gnu-gdb build/main -ex "target remote:1234"
```

- 注意：`make gdb` 加载的是**内核** ELF。要单步 bootblock，需手动
  `riscv64-unknown-linux-gnu-gdb build/bootblock -ex "target remote:1234"`。
- bootblock 无 C 栈、不能中断；内核侧 `main` 可下断点。

## P2-1. 构建

```bash
make all            # bootblock + 内核 + 12 个 app → build/kernel.img + build/apps.img
                    # 末尾打印布局核算（[layout] 各行）；改过 app 源码后建议全量
```

## P2-2. 运行（QEMU）

```bash
make run            # 或 .scratch/p2-run.sh <日志> "6|loadbootd" "8|print1" …
```

1. 等 ~6 秒出现 U-Boot `=> ` 提示符，输入 `loadbootd`（DASICS 地址隔离；任务 1/2
   阶段 `loadboot` 亦可）；
2. 内核提示后**一行一个任务名**（`list` 打印应用信息表，空行开始调度）；
   任务1/2 用 print1 print2 fly / lock1 lock2；任务3/4 用六任务；任务5 用 fly1..fly5；
3. 换一组任务按 **Ctrl+C**（内核热重启回提示符）；退出 QEMU 用 Ctrl+a 再按 x。

## P2-3. 自动化验证（`.scratch/` 下两个临时工具，gitignore）

```bash
P2RUN_NO_PKILL=1 .scratch/p2-run.sh <日志> "6|loadbootd" "8|print1" "1|print2" "1|" "15|"
python3 .scratch/emu.py <日志>              # 还原最终屏幕
python3 .scratch/emu.py <日志> --watch 3,4  # 某行的内容变化时间线（核对锁交接等）
```

- 骨架按"延时|文本"注入输入（空行写 `"1|"`，`\x03` 发 Ctrl+C）；并行跑实验时
  **必须设 `P2RUN_NO_PKILL=1`**，否则骨架会误杀别的 QEMU；
- 测"公平性/时间"必须固定时间基准：`QEMU_EXTRA="-icount shift=3,sleep=off"`
  （宿主墙钟噪声 ±5~10% 会淹没策略差异），并记录 `/proc/loadavg`；
- 内核临时排查用 `printl`（只进 QEMU 的 `-D` 日志，不污染屏幕），**提交前删干净**。

## P2-4. 已知口径

- 锁：互斥 = burst 窗口零重叠；换手是相位粒度（1/4 节拍下 ~64% 一次一换）；
- 五机同速：判据 = 累计进度锁步（总格数差 <1%、1 秒窗口速率差 <10%）；
- 文档里的每个数字都要标测量版本与口径（`-icount` 的数字才可复现）。

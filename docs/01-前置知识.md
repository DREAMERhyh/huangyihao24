# 01 前置知识

> 面向"没写过汇编、不懂 ELF"的读者。目标：能读懂后续逐行讲解即可。不求会写，求**能看**。

## 1. 七条最小认知

1. **指令就是数字**：CPU 只会执行编码成 32/16 位二进制数的指令。汇编语言是这些
   数字的"给人看的名字"。`objdump -d` 把可执行文件里的数字还原成人名。
2. **寄存器 = CPU 内部的几个槽**：读写最快，函数参数、返回值、临时变量都在寄存器里。
   RISC-V 的通用寄存器叫 `x0…x31`，还有广为人知的名字：
   - `ra`(x1)：返回地址寄存器——`call`/`jal` 会把它设成"下一条指令的位置"；
   - `sp`(x2)：栈指针——栈向下生长，`sp` 永远指着栈顶；
   - `a0…a7`：函数参数/返回值（按需使用）；
   - `s0…s11`：callee-saved——被调用方承诺不改它们；
   - `t0…t6`：临时寄存器，随便用。
3. **栈 = 一段内存**：函数调用要用栈存放 return address、局部变量。栈顶地址记在 `sp`。
   本项目里内核栈顶 `0x50500000`、用户程序共享栈顶 `0x50400000`，都向下生长。
4. **内存没有"名字"，只有地址**：字符串、代码、数据结构最终都是内存里的一段字节。
   `objdump`/`nm`/`readelf` 帮你在地址和符号之间换算。
5. **ELF = 可执行文件格式**：编译器产生的 `.o`/链接器产生的可执行文件都是 ELF。
   里面最关键的是 **program header（程序头，PT_LOAD 段）**，它告诉加载器：
   "把文件里这一片拷贝到内存的哪个虚拟地址"。createimage 干的就是这件事的"手工版"。
6. **镜像 = 光盘/SD 卡的字节拷贝**：bootblock/内核/app 的"可执行内容"（不是整个 ELF
   文件）按顺序拼起来，就是镜像 `build/image`。BIOS 按**扇区**（512 字节）寻址读。
7. **BIOS = 别人写好的"系统函数库"**：我们的代码运行在 S 态，要打印/读卡得"陷入"
   更高权限（M 态）的 U-Boot 帮忙。`0x50150000` 是一条 `ecall+ret`，ecall 让 CPU
   陷入 U-Boot，U-Boot 看寄存器 `a7` 知道要干什么，做完把结果写回 `a0` 再 `mret` 回来。

## 2. 你会反复见到的 RISC-V 指令（读代码够用）

| 指令 | 名字全称 | 干什么 | 本项目出现处 |
|---|---|---|---|
| `li rd, imm` | load immediate | rd = 常数 | （伪指令，展开成 lui/addi 等） |
| `la rd, sym` | load address | rd = 符号的地址 | 到处用于取字符串/变量的地址 |
| `lui rd, imm20` | load upper immediate | rd = 常数高 20 位 | 大常数 |
| `auipc rd, imm20` | add upper immediate to pc | rd = pc + 常数高 20 位 | **位置无关取址**：`auipc t0,0` 让 t0=当前指令地址 |
| `addi rd, rs, imm12` | add immediate | rd = rs + 12 位常数 | 配合 lui/auipc 拼地址 |
| `jal rd, label` | jump and link | 跳到 label，rd=下一条地址（通常 rd=ra） | `call main`、`jal kernel` |
| `jalr rd, rs, off` | jump and link register | 跳到 rs+off，rd=返回地址 | 间接跳转、返回（`ret`=`jalr x0,ra,0`） |
| `beq/bne/bge/beqz(伪)` | branch | 条件跳转（±4KB 内） | 循环、判断 |
| `j label` | jump | 无条件跳转 | 死循环 `j stop` |
| `lh` / `lw` / `lb` | load half/word/byte | 从内存读 2/4/1 字节，符号扩展 | 读 `0x1fc` 的内核扇区数 |
| `sd` / `sw` / `sb` | store | 把寄存器值写回内存 | 存参数、清 BSS）
| `move rd, rs`（伪） | move | rd = rs | 传参 |
| `ecall` | environment call | 陷入更高权限（本项目进 U-Boot） | 在 0x50150000 里 |
| `mret` | machine-mode return | 从 trap 返回 | 在 U-Boot 里 |

> 注意：`la`/`la ra,1f` 里的 `1f` 是个**数字符号**（forward label），指"下面第一个
> 数字标签 1: 的位置"，用于取"我这条指令之后那条指令"的返回地址。

## 3. ELF 里我们只关心这几样

`riscv64-unknown-linux-gnu-readelf -h build/main`：看 `Entry point`（入口地址）、
`e_phnum`（程序头个数）。

`riscv64-unknown-linux-gnu-readelf -lW build/main`：看 program header。重点是：

```
Type           Offset   VirtAddr           FileSiz  MemSiz   Flg
LOAD           0x1000   0x50201000         0x5b0    0x5e8    RWE
```

| 字段 | 含义 | 我们的用法 |
|---|---|---|
| `Offset` | 这段内容在 ELF 文件里的偏移 | createimage 从这里读字节 |
| `VirtAddr` | 这段内容在内存里的地址 | 内核 0x50201000 / app 0x52000000… |
| `FileSiz` `p_filesz` | 文件里占多少字节 | **镜像里实际写入的大小**；BSS 不在其中 |
| `MemSiz` `p_memsz` | 内存里最终占多少字节 | 比 filesz 多出的部分 = BSS（运行时清零） |
| `Flg` | 可读/写/执行 | 本项目镜像不严格区分 |

> **字节计数口径**：自建 createimage 的"该文件实际扇区数"= 所有 PT_LOAD 段的
> `p_filesz` 之和向上取整到 512。**不是 `p_memsz`**——BSS 部分由 head.S / crt0 在
> 运行时清零，不进镜像。（官方 createimage 按 `p_memsz` 写并 0x400 对齐，口径不同，
> 见 `log/工作流程.md` §5。）

## 4. 链接脚本 riscv.lds 里我们要知道的名词

- `TEXT_START`：链接起点。Makefile 用 `-Wl,--defsym=TEXT_START=<各产物的地址>` 传进来
  （bootblock=0x50200000、内核=0x50201000、app=0x52000000+i*0x10000）。
- `.entry_function` 段：head.S / crt0.S 的 `_start` 放这里，链接脚本把它排在 `.text`
  最前面 —— 这保证了"入口就是整个产物的第一个字节"。
- `__bss_start` / `__BSS_END__`：链接器在任何布局下都会给出这两个**绝对符号**，
  指 BSS 的起止。head.S 和 crt0 都靠它们清零，永远不需要硬编码地址。

## 5. QEMU 与"SD 卡"

QEMU 是模拟器。我们给它的磁盘是一个普通文件：`-drive file=build/image`。
U-Boot 把它当一块 virtio 磁盘，BIOS 的 `bios_sd_read` 就是"从这个文件按扇区读"。
所以**想让代码"读到"什么，就把什么按扇区摆进 build/image**——这就是 createimage 的
意义；也是任务 5"把内核和应用分成两个镜像"后，要用 `cat` 把它们拼回同一个文件的
原因（QEMU 只挂了一块盘）。

## 6. 三个自查工具（后面高频出现）

```bash
riscv64-unknown-linux-gnu-readelf -h build/main    # 入口、程序头数量
riscv64-unknown-linux-gnu-readelf -lW build/main   # PT_LOAD 的 filesz/memsz/vaddr
riscv64-unknown-linux-gnu-nm      build/main       # 符号表（__bss_start 在哪儿）
riscv64-unknown-linux-gnu-objdump -d build/main    # 反汇编（指令级真相）
xxd  -s <偏移> -l <长度> build/image                 # 看镜像/文件原始字节
```

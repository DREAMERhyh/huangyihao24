# 术语表 + 地址速查表（glossary）

> 教学文档的"字典"：名词解释 + 关键地址/偏移速查。其他文档提到这些地址时，与本文
> 保持一致（抽查依据）。

## 1. 关键内存地址速查

| 地址 | 含义 | 备注 |
|---|---|---|
| `0x50000000 – 0x501fffff` | U-Boot（BIOS/BBL）占据区 | QEMU `-kernel u-boot` |
| `0x50150000` | **BIOS 统一入口**：一条 `ecall` + `ret` | 功能号放 `a7`，参数放 `a0/a1/a2…` |
| `0x50200000` | **bootblock 加载/运行地址**（镜像扇区 0） | `loadboot` 跳到这里；代码 ≤512B |
| `0x502001f8` | 镜像信息字段：**app 数目**（2B 小端） | bootblock `lh` 读 → a1 |
| `0x502001fc` | 镜像信息字段：**内核扇区数 K**（2B 小端，实际值） | bootblock `lh` 读（官方推荐约定） |
| `0x502001fe` | 镜像信息字段：**签名 `55 aa`** | 官方引导签名，不许覆盖 |
| `0x50201000` | **内核入口**（head.S `_start`） | bootblock 读到这并 `jal` 过来 |
| `0x50400000` | **app 共享栈顶**（所有用户程序共用一个栈，向下生长） | 内核栈独享 0x50400000–0x50500000 |
| `0x50500000` | **内核栈顶**（KERNEL_STACK，向下生长） | 官方指定 |
| `0x51ffff00` | **内核 BIOS 跳转表**（KERNEL_JMPTAB_BASE，5 槽×8B） | `init_jmptab()` 填充 |
| `0x52000000 + i*0x10000` | **第 i 个用户程序的窗口/入口** | 每 app 64KB |

## 2. 镜像信息字段记忆口诀

```
第 0 扇区尾部：  0x1f8 app 数 | 0x1fc 内核扇区数 | 0x1fe 55 aa
```

- `0x1fc` 是**实际**内核扇区数（`NBYTES2SEC(p_filesz)`），bootblock 精确读入内核；
- `0x1f8` 自 **Task 4 后**不再由内核直读，而是 bootblock 传给 a1（Task 4 前内核直读，
  依赖 U-Boot 预读 2 扇区——那是一条已废弃的隐藏依赖）。

## 3. 基础单位与常量

| 名 | 值 | 说明 |
|---|---|---|
| 扇区大小 | 512 B | BIOS 一次读写的单位 |
| `TASK_MAXNUM` | 16 | AppInfo 最多记录 16 个 app |
| `TASK_NAME_LEN` | 16 | app 名字段长度（含 `\0`） |
| `TASK_SIZE` | 0x10000 (64KB) | 每个 app 的内存窗口 |
| `A`（AppInfo 区扇区数） | 1 | 由 `_Static_assert` 守护：16×28 ≤ 512 |
| `task_info_t` | 28 B | name[16]+start+sector_num+vaddr_entry |

## 4. 名词解释（一句话版）

| 术语 | 解释 |
|---|---|
| BIOS / BBL / U-Boot | 高特权"系统函数库"，代码在 M 态；我们 S 态代码经 `0x50150000` 的 ecall 请求它服务 |
| bootblock | 镜像扇区 0 的 512B 引导程序，纯汇编，无 C 栈；打印、读内核后把控制权交给内核 |
| 内核 | head.S + main.c 等编译产物，链接到 0x50201000；管理内存/输入/加载用户程序 |
| BSS | 未初始化数据段（如 `buf[50]`、`tasks[]`）；不在镜像里，运行时清零 |
| `p_filesz` / `p_memsz` | ELF 段"文件里的大小" / "内存里的大小"；镜像只装 `p_filesz` |
| createimage | 宿主机工具，把各 ELF 的 PT_LOAD 内容按布局拼进镜像并写信息字段 |
| AppInfo | 内核镜像内记录各 app 信息（名字/相对扇区/大小/入口）的 `task_info_t` 数组 |
| 跳转表 `0x51ffff00` | 内核把 BIOS 函数指针放这里，`bios_*` 都经它间接调用；app 复用 |
| crt0 | 每个用户程序的"入场前"代码：保存内核现场、设共享栈、清 BSS、调 main、返回 |
| `load_task_img` | loader 里按名字匹配并在 SD 上读回目标 app 的函数 |
| `_Static_assert` | C11 编译期断言（task.h 三条护栏，守护 A=1 等前提） |
